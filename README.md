# 🚴 Adventure Works Sales Performance Dashboard

## 📊 Project Overview

This project presents an interactive executive sales dashboard built in Microsoft Excel using the Adventure Works sales dataset (2011–2016).

The objective was to transform raw transactional sales data into meaningful business insights through data cleaning, KPI development, PivotTables, PivotCharts, and interactive dashboard design.

The dashboard enables users to explore sales performance across product categories, countries, customer demographics, and time periods using slicers and a timeline.

---

## 🎯 Business Problem

The dashboard was designed to answer the following business questions:

- Which product categories generate the highest revenue and profit?
- Which countries contribute the most to overall sales?
- Which customer demographics purchase the most products?
- How has sales performance changed over time?
- What is the company's overall profitability?

---

## 🔍 Key Insights

Some key findings from the analysis include:

- Bikes generated the highest overall revenue.
- The United States contributed the highest sales revenue.
- Adults (35–64 years) represented the largest customer segment.
- Overall profit margin remained approximately 44%.
- Sales records indicate that Clothing and Accessories appear from 2013 onwards, suggesting an expansion of the product portfolio.
